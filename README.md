# Hardware & Chip Design Job Scanner

An automated scraping and notification pipeline designed to detect student and entry-level chip design positions across multiple career portals.

## Features
* **Automated Scraping:** Python-based parser targeting hardware and VLSI career pages.
* **CI/CD Automation:** Scheduled execution via GitHub Actions workflows.
* **Instant Alerts:** Real-time push notifications delivered directly to a Telegram channel via the Telegram Bot API.
